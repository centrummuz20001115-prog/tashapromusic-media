# TashaProMusic — Media

Zasoby wizualne i medialne marki **TashaProMusic** (Centrum Rozwoju Muzycznego,
Bolesławiec). To repozytorium jest źródłem prawdy dla logo, kolorów, zdjęć,
wideo i materiałów social media wykorzystywanych na stronie i w komunikacji.

> Візуальні та медіаресурси бренду TashaProMusic. Це репозиторій — єдине
> джерело правди для логотипів, кольорів, фото, відео та матеріалів соцмереж.

## 📁 Struktura

```
brand/
  logo/          # logo i favicon (SVG)
  tokens/        # kolory marki, typografia (colors.json)
photos/
  hero/          # zdjęcia główne (nagłówek strony)
  lessons/       # lekcje: wokal, pianino
  vivakids/      # zespół VIVAKIDS
  events/        # koncerty, gale, wydarzenia
  studio/        # VIVA STUDIO — nagrania
video/
  vivakids/      # teledyski, występy
audio/           # nagrania, dema
social/
  instagram/ facebook/ tiktok/ youtube/   # gotowe posty i grafiki
```

## 🎨 Marka w skrócie

| Element | Wartość |
|---------|---------|
| Kolory | złoto `#E7C067` · fiolet `#8B5CF6` · tło `#0A0912` · cream `#F6F1E7` |
| Typografia | *Cormorant Garamond* (nagłówki) + *Manrope* (tekst) |
| Sub-marki | VIVAKIDS · VIVA STAGE · VIVA STUDIO |

Pełna paleta i tokeny: [`brand/tokens/colors.json`](brand/tokens/colors.json).

## 🖼️ Wskazówki do zdjęć

- Ciepłe, złociste światło; naturalne kadry (instrument, dłonie na klawiszach, nuty, scena).
- Format: preferowany JPG/WEBP dla zdjęć, SVG/PNG dla grafik z przezroczystością.
- Nazewnictwo: `sekcja-opis-NN.jpg` (np. `vivakids-koncert-01.jpg`).
- Prawa: dodawaj wyłącznie materiały, do których masz prawa i zgody (RODO —
  szczególnie zdjęcia dzieci).
